# Tasks

List of the user's tasks.

## Items

- home link → Home/initial
- tasks link → Tasks/initial
- projects link → Projects/initial
- settings link → SettingsProfile/initial
- log out link → LoginScreen/initial
- new task button → NewTask/initial
- all tab → Tasks/initial
- open tab → Tasks/open
- done tab → Tasks/done
- search input
- search button
  - if search is empty → Tasks/initial
  - if search contains `release` → Tasks/search_results
  - else → Tasks/no_results
- Fix checkout bug row → TaskCheckoutBug/initial
- Write release notes row → TaskReleaseNotes/initial
- Update privacy policy row → TaskPrivacyPolicy/initial
